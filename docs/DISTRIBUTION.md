# ขอบเขตการแจก

- ใช้ repository เดียว แยกโค้ดแพลตฟอร์มใน platforms/macos และ platforms/windows
- แยก release artifacts และผลตรวจสอบแต่ละแพลตฟอร์มอย่างชัดเจน
- แจกเฉพาะโค้ดตัวแพตช์ที่มีสิทธิ์แจก คำแปล และเอกสาร ไม่แจกตัวแอป vivo หรือ archive ของแอป
- ห้ามนำโฟลเดอร์ผลงานแพตช์เดิมทั้งโฟลเดอร์ขึ้น GitHub เพราะมีตัวแอปและสำรอง
- การเลือกใบอนุญาตของโค้ดใหม่ยังรอเจ้าของโครงการตัดสินใจ เอกสารนี้ไม่ได้ให้สิทธิ์ในซอฟต์แวร์หรือเครื่องหมายการค้าของ vivo หรือโค้ดบุคคลอื่น
- ผู้ใช้เลือกเผยแพร่ repository แบบสาธารณะ ส่วน Windows พัฒนาโดยใช้ Cursor บนอีกเครื่อง และแยกตรวจผลทดสอบจาก macOS
- macOS มีตัวติดตั้งรุ่นทดลองพร้อมคำสั่งติดตั้งแล้ว ยังรอทดสอบเปิดแอปและฟังก์ชันจริงก่อนออก release ใช้งานทั่วไป
