# ชุดข้อมูลจาก Windows

เตรียมเฉพาะสิ่งต่อไปนี้เพื่อการตรวจ ไม่ต้องส่งตัวแอปเต็มหรือสำรองทั้งเครื่อง:

- สคริปต์/ซอร์สตัวแพตช์ และไฟล์คำแปลที่จัดทำเอง
- รุ่น Office Kit จีนที่รองรับและสถาปัตยกรรม เช่น x64 หรือ ARM64
- รายชื่อไฟล์แอปที่แก้ พร้อม SHA-256 ก่อนและหลัง และรายการเปลี่ยนข้อความถ้ามี
- ขั้นตอนติดตั้ง สำรอง และย้อนกลับ รวมโปรแกรมที่จำเป็นต้องติดตั้งเพิ่ม
- ผลทดสอบฟอร์ม การบันทึก/แก้ไข การเชื่อมต่อและการโอนไฟล์ พร้อมข้อจำกัด
- ที่มาและใบอนุญาตของโค้ดหรือเครื่องมือภายนอกที่ใช้

ลบ tokens, passwords, cookies, บัญชี/ชื่อเครื่อง, paths ส่วนตัว, logs ที่มีข้อมูลผู้ใช้ และข้อมูลในโทรศัพท์ออกก่อนส่ง ภาพตัวอย่างควรใช้ข้อมูลทดสอบและปิดข้อมูลส่วนตัว

ถ้ามีเพียงแอปที่แก้เสร็จแล้ว ให้แจ้งก่อน ยังไม่ควรอัปโหลดไฟล์นั้นขึ้น GitHub
