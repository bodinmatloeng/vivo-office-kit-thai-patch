# ตัวติดตั้ง Mac แบบ PKG — รุ่นทดลอง 0.2.0

สำหรับ **Mac ชิป Apple (M1 เป็นต้นไป), macOS 11 ขึ้นไป และ vivo Office Kit จีน 7.0.6 ที่ checksum ตรงกับฐานที่รองรับ**

ผู้ใช้ไม่ต้องติดตั้ง Python, Node.js หรือเครื่องมือพัฒนา ตัวติดตั้งเขียนด้วย Swift ใช้ Foundation, AppKit และ CryptoKit ที่มากับ macOS

## วิธีติดตั้ง

1. ติดตั้งแอปจีนจาก vivo และทดลองเปิดให้ผ่านก่อน
2. ปิด vivo Office Kit ผ่านเมนูออก
3. เปิดไฟล์ `Vivo-Thai-macOS-0.2.0-preview.pkg` และทำตามหน้าต่าง Installer ของ macOS
4. หาก macOS ขอสิทธิ์ผู้ดูแล ให้ยืนยันด้วยระบบของ macOS เอง
5. เปิด vivo Office Kit ตามปกติ

แพ็กเกจตรวจฐานก่อนทำงาน ติดตั้งเครื่องมือ `Vivo Thai Patch.app` ใน Applications แล้วสำรองและแก้เฉพาะ app.asar ของ vivo ไม่รวมตัวแอป vivo หรือข้อมูลผู้ใช้ในแพ็กเกจ

หากมีแพตช์อิสระรุ่นก่อนที่รองรับติดตั้งแล้ว จะไม่เขียน archive ซ้ำหรือสร้างสำรองใหม่ สำรองเดิมยังเป็นสำรองที่ต้องใช้ย้อนกลับ

## สำรองและย้อนกลับ

สำหรับการติดตั้งใหม่บนฐานจีน สำรองแยกแต่ละครั้งอยู่ที่:

```text
/Library/Application Support/VivoOfficeKitThaiPatch/backups/stock-7.0.6-<รหัสเฉพาะ>/
```

ปิด Office Kit แล้วเปิด **Vivo Thai Patch** ใน Applications เลือก **คืนภาษาจีน** และเลือกโฟลเดอร์สำรองที่มี `app.asar` กับ `receipt.json` โปรแกรมจะตรวจ checksum และไม่เขียนทับแอปที่ไม่รู้จัก

สำรองจากสคริปต์อิสระรุ่น 0.1.x ใช้ได้เมื่อเลือกโฟลเดอร์สำรองนั้นเอง โปรแกรมนี้ไม่ค้นหรืออ่านสำรองอื่นโดยอัตโนมัติ

## ข้อจำกัด

- PKG ยังไม่ได้ลงลายเซ็น Developer ID และยังไม่ผ่าน notarization หาก macOS ปฏิเสธ ให้หยุดและรายงาน ไม่ปิด Gatekeeper/SIP หรือเอา quarantine ออก
- ไม่ resign หรือแก้ code signing ของแอป vivo
- รองรับเฉพาะ checksum ที่ระบุ ไม่ใช่ทุกไฟล์ที่ใช้เลขรุ่น 7.0.6 เหมือนกัน
- ยังมีจีนบางส่วนในวันที่ หมวด เขตเวลา toast และเมนู native รวมถึงข้อความที่มาจากโทรศัพท์/บริการภายนอก
- การอัปเดตแอป vivo อาจทับแพตช์
- ไม่รองรับฐาน English Basic หรือ Thai V1–V5 เดิมที่ผูกกับแพตช์อังกฤษ
- ต้องแยกผลทดสอบ native engine, การเปิดแอปหลังแพตช์ และการติดตั้งผ่านหน้าต่าง PKG ดูผลจริงใน validation.json

## สำหรับผู้พัฒนา

`build_pkg.py` ใช้ Python เฉพาะบนเครื่องผู้พัฒนาเพื่อเรียก swiftc, pkgbuild และ productbuild เครื่องผู้ใช้ไม่ต้องมี Python

```sh
python3 build_pkg.py --work /absolute/build-directory --output /absolute/Vivo-Thai-macOS-0.2.0-preview.pkg
```

ต้องตรวจผล native build และบันทึก `native_patched_sha256` ก่อนสร้างแพ็กเกจ ไม่มีแอป vendor ใน repository หรือ payload

## ผลทดสอบรุ่นนี้

- Native engine: ติดตั้ง สำรอง ติดตั้งซ้ำ ย้อนกลับ สร้างซ้ำ และตรวจสมาชิก ASAR 28,686 รายการผ่านบนสำเนา
- ติดตั้ง native engine จากแอปจีนจริงแล้วเปิดเป็นไทยได้
- หน้าต่างเครื่องมือ: ตรวจพบแพตช์ที่มีอยู่และไม่เขียนซ้ำ
- PKG: หน้าต่าง Installer ของ macOS รายงานติดตั้งสำเร็จบนเครื่องที่มีแพตช์อิสระอยู่แล้ว ตรวจ binary ที่ติดตั้งตรงกับ build และ checksum app.asar คงเดิม
- ยังไม่ได้ทดสอบ PKG ทั้งกระบวนการบน Mac อีกเครื่องที่เริ่มจากต้นฉบับจีน การเชื่อมต่อ/สะท้อนหน้าจอ/ส่งไฟล์ผ่านในรอบตัวติดตั้ง Python ก่อนหน้า สมาชิกไฟล์ในแพตช์ native ตรวจตรงกัน แต่ไม่ได้ทดสอบทุกฟังก์ชันซ้ำด้วย PKG
- validation.json ใน repository รวมผลทดสอบภายหลังสร้างแพ็กเกจ ส่วนไฟล์ภายใน PKG บันทึกผล engine ณ เวลาสร้าง
