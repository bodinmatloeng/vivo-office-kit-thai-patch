# ตัวติดตั้ง macOS — รุ่นทดลอง 0.1.1

ตัวติดตั้งนี้เขียนใหม่ด้วย Python standard library ไม่ใช้โครงตัวติดตั้งหรือการแก้ระบบของแพตช์ภาษาอังกฤษ ใช้คำแปลไทยที่จัดทำไว้ในโครงการ

**ผ่านการติดตั้ง เปิดแอป สร้าง/แก้ไขสิ่งที่ต้องทำและกำหนดการ เชื่อมต่อ Wi-Fi เปิดจัดการไฟล์ สะท้อนหน้าจอ ส่งไฟล์ทดสอบ และย้อนกลับบน Mac เครื่องทดสอบแล้ว ยังเป็นรุ่นทดลองสำหรับฐานที่ระบุเท่านั้น**

## รองรับ

- vivo Office Kit China 7.0.6 บน Mac Apple Silicon เฉพาะต้นฉบับที่ SHA-256 ตรงกับ translations.json
- ต้องมี Python 3.9 ขึ้นไป ตัวติดตั้งไม่ดาวน์โหลด dependencies ให้อัตโนมัติ
- ไม่รองรับแอปที่ลง English Basic หรือ Thai V1–V5 แล้ว และไม่แทนที่แพตช์เดิมโดยอัตโนมัติ
- คำแปล 2,933 ตำแหน่ง รวมข้อความซ้ำ; 1,262 คู่ข้อความต้นทาง–คำแปลไม่ซ้ำ ใน 41 ไฟล์
- ไม่รวมตัวแอป ไฟล์ ASAR หรือไฟล์สำรอง ผู้ใช้ต้องรับแอปต้นฉบับจาก vivo เอง

## ตรวจสอบก่อนติดตั้ง

เปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```sh
python3 installer.py check
```

คำสั่งนี้ตรวจรุ่น checksum และตำแหน่งคำแปล โดยไม่แก้แอป หากไม่ตรงให้หยุด ไม่ควรเปลี่ยน manifest เพื่อฝืนติดตั้ง

## ติดตั้งรุ่นทดลอง

ปิดแอปตามปกติ จากนั้นเปิด `ติดตั้ง.command` หรือรัน:

```sh
python3 installer.py install
```

โปรแกรมจะสำรอง app.asar เดิมแบบแยกโฟลเดอร์ ตรวจ SHA-256 สร้างและตรวจ archive ใหม่ ก่อนแทนที่ไฟล์แบบ atomic เมื่อพบรุ่นนี้ติดตั้งแล้วจะไม่เขียนซ้ำหรือสร้างสำรองเพิ่ม

ค่าเริ่มต้นของแอปคือ `/Applications/pcsuite.app` เปลี่ยนได้ด้วย `--app "/path/to/pcsuite.app"` หากไม่มีสิทธิ์เขียนจะหยุด ไม่ขอ sudo เปลี่ยนสิทธิ์ หรือปิดระบบป้องกันให้อัตโนมัติ

## สำรองและย้อนกลับ

สำรองเริ่มต้นอยู่ใต้:

```text
~/Library/Application Support/vivo-office-kit-thai-patch/backups/stock-7.0.6-<รหัสเฉพาะ>/
```

เก็บทั้ง `app.asar` กับ `receipt.json` ไว้ในเครื่อง ไม่อัปโหลดสำรองขึ้น GitHub เพราะมีซอฟต์แวร์ vendor และ path ในเครื่อง

เปิด `ย้อนกลับ.command` แล้วใส่โฟลเดอร์สำรองที่รายงาน หรือรัน:

```sh
python3 installer.py revert --backup "/path/to/stock-7.0.6-รหัสเฉพาะ"
```

การย้อนกลับนี้คืน **ต้นฉบับจีนก่อนติดตั้งตัวใหม่นี้** ไม่ใช่ V5 → V4 หากแอปถูกอัปเดตหรือสำรองเสียหาย โปรแกรมจะปฏิเสธการเขียนทับ

## สิ่งที่เปลี่ยนและข้อจำกัด

- เปลี่ยนเฉพาะ string literals และค่าคลังภาษา รักษา keys, placeholders และโครงสร้างโค้ดเดิม
- ไม่แก้ main.js, business logic, protocol, ระบบเชื่อมต่อ หรือระบบคำนวณวันเวลา ไม่เรียก codesign และไม่เปลี่ยน Gatekeeper/SIP
- การทำงานของการเชื่อมต่อและ Mirroring เป็นของแอปจีนเดิม ไม่รวมการแก้ข้อจำกัดจากแพตช์อังกฤษ
- ยังมีข้อความจีน/อังกฤษบางส่วน เช่นข้อความประกอบวันเวลา/การทำซ้ำ ข้อความจากบริการภายนอกหรือหน้าจอโทรศัพท์ ตัวติดตั้งนี้ไม่ได้รับรองว่าแปลครบทั้งแอป
- ผลข้างต้นเป็นการทดสอบตัวติดตั้งใหม่นี้จากแอปจีนเดิม ไม่ใช่อ้างจาก V5 เดิม การส่งไฟล์ยืนยันจากประวัติในแอป ยังไม่ตรวจ checksum ปลายทาง ส่วนการซิงค์ปฏิทินข้ามอุปกรณ์และสำรอง/กู้คืนข้อมูลโทรศัพท์ยังไม่ได้ทดสอบแยก
- การแก้ resources อาจทำให้การตรวจความสมบูรณ์ของแอปจาก vendor ไม่ผ่าน และการอัปเดตอาจทับคำแปล หากระบบไม่อนุญาตให้เปิด ให้หยุดและรายงาน ไม่ปิดระบบป้องกัน

## การทดสอบโค้ด

```sh
python3 -m unittest discover -s tests
```

ชุดทดสอบใช้ archive สังเคราะห์ ไม่มีแอปหรือข้อมูลผู้ใช้ ผลทดสอบบนสำเนาต้นฉบับจริงอยู่ใน validation.json
