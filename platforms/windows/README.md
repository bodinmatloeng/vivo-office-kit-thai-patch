# แพตช์ภาษาไทยสำหรับ Windows

สคริปต์นี้เปลี่ยนข้อความใน **vivo办公套件 รุ่นจีน 7.0.6** บน Windows ให้เป็นภาษาไทย ผู้ใช้ต้องติดตั้งแอปจาก vivo เอง ชุดนี้ไม่มีตัวแอป

## ฐานที่รองรับ

| รายการ | ค่า |
| --- | --- |
| โปรแกรม | vivo办公套件 |
| ผู้เผยแพร่ | 维沃移动通信有限公司 |
| รุ่น | 7.0.6 |
| ระบบ | Windows 64 บิต (ทดสอบบน Windows 11 รุ่น 10.0.26200, สถาปัตยกรรม AMD64) |
| ไฟล์ที่แพตช์แก้ | `resources\app.asar` ในโฟลเดอร์ติดตั้ง |
| SHA-256 ของ app.asar ต้นฉบับจีน | `35FFB46AB7979DDC5250C66393DD6FB35210739DAB4FD125A94462F72A7F96E0` |
| ขนาดไฟล์ต้นฉบับ | 365,088,330 ไบต์ |

ค่า SHA-256 นี้เป็นของไฟล์ต้นฉบับก่อนแก้ภาษา ไม่ได้แนบไฟล์นั้นมากับชุดแจก

## สิ่งที่มีในชุดนี้

- `patch-thai.js` ตัวแพตช์
- `install-thai.bat` ติดตั้งภาษาไทย
- `restore-chinese.bat` คืนภาษาจีนจากสำเนาที่สคริปต์เก็บไว้ในเครื่องผู้ใช้

สคริปต์จะสำรอง `app.asar` เดิมไว้ที่ `%LOCALAPPDATA%\VivoOfficeKit-Thai\app.asar.original` ก่อนเขียนทับครั้งแรก การคืนค่าคือคัดลอกสำเนานั้นกลับที่เดิม แล้วตั้ง `config.ini` กลับเป็น `LanguageID=2052` และ `LanguageTag=zh_CN`

คำแปลส่วนใหญ่ถูกอ่านจากคลังภาษาไทยที่มากับแอปที่ผู้ใช้ติดตั้งเอง ตอนรันแพตช์ ไม่ได้คัดลอกคลังภาษาของ vivo มาไว้ในชุดแจก คำสั้นที่ไม่มีคู่แปลตรงตัวอยู่ในสคริปต์ เช่น ปฏิทิน อัลบั้ม กำหนดการ

## สิ่งที่ยังไม่มี

- ยังไม่ตรวจ SHA-256 ของแอปก่อนติดตั้ง และยังไม่ตรวจ checksum หลังเขียนไฟล์ ถ้าแอปไม่ใช่รุ่น 7.0.6 สคริปต์จะพยายามแก้แล้วอาจไม่พบจุดที่รองรับ
- ยังไม่มีตัวติดตั้งแบบไม่ต้องใช้ Node.js ต้องติดตั้ง [Node.js](https://nodejs.org/) ก่อน
- ประโยคยาวที่แอปประกอบเองทีละท่อนอาจยังเป็นภาษาจีน
- ชื่อบนแถบหน้าต่างยังเป็น vivo办公套件 เพราะเป็นชื่อโปรแกรม
- ยังไม่ได้ทดสอบครบรอบถอนการติดตั้งแล้วลงใหม่ทั้งชุด ผลที่ตรวจแล้วคือสร้างไฟล์ที่แก้ภาษาจากต้นฉบับจีนชุดนี้ แล้วตรวจไวยากรณ์ของชุดสคริปต์ในแอปว่ายังเปิดได้

## วิธีติดตั้ง

1. ติดตั้ง vivo办公套件 7.0.6 จาก vivo
2. ติดตั้ง Node.js
3. ดับเบิลคลิก `install-thai.bat`
4. ถ้า Windows ถามสิทธิ์ผู้ดูแล ให้กด Yes
5. รอจนสคริปต์เปิดแอปให้ใหม่

ถ้ารันซ้ำบนเครื่องที่ใส่ภาษาแล้ว สคริปต์จะไม่เขียนไฟล์แอปซ้ำ

## วิธีย้อนกลับ

ดับเบิลคลิก `restore-chinese.bat` ต้องมีสำเนาที่เกิดจากการติดตั้งแพตช์ครั้งแรก

## ข้อห้าม

ห้ามนำตัวแอป vivo, ไฟล์ `.asar`, ไฟล์สำรอง, ข้อมูลผู้ใช้ หรือรหัสผ่านไปแจกต่อ ชุดนี้แจกได้เฉพาะสคริปต์และเอกสารนี้
